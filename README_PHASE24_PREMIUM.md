# CelebrateVerse — Phase 24 Premium

Phase 24 adds the premium feature layer without touching real checkout/payment logic.

## Included

- Custom domain settings UI (stores the desired domain; DNS/hosting connection remains a hosting-side step)
- Remove CelebrateVerse branding in premium preview mode
- Premium templates: Romantic, Luxury, Galaxy, Birthday, Anniversary, Minimal
- Premium animations: Fade, Zoom, Flip, Cinematic
- Premium music previews using browser audio
- Premium photo frames: Circle, Square, Rounded, Heart, Star, Polaroid, Film
- Premium preview/unlock switch for testing before real payment is enabled
- Service-worker cache bumped to v24

## Important

Real payment/unlock is intentionally not implemented in this phase. The premium layer is ready to connect to the final payment flow later.
